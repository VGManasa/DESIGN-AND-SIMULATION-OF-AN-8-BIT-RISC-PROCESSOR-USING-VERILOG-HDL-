# DESIGN-AND-SIMULATION-OF-AN-8-BIT-RISC-PROCESSOR-USING-VERILOG-HDL-
This project implements an 8-bit single-cycle RISC processor using Verilog HDL, featuring a simplified yet efficient instruction set. The design is simulated in ModelSim and deployed on the DE10-Lite FPGA, with integrated peripheral control including LED counters, switches, keys, and 7-segment display output.
